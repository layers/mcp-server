# Contributing

Contributions are welcome through GitHub pull requests.

- Do not commit credentials, customer data, private repository paths, or
  internal incident details.
- Use a company address or GitHub-provided `noreply` address for public commit
  metadata if you do not want a personal email retained in Git history.
- Add or update focused tests for behavior changes.
- Keep stdout reserved for MCP JSON-RPC frames; diagnostics belong on stderr.
- Report security issues privately through [SECURITY.md](SECURITY.md).

By submitting a contribution, you agree that it is licensed under this
repository's Apache License 2.0.
