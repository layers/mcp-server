# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email [security@layers.com](mailto:security@layers.com) with:

- the affected package version;
- a minimal reproduction or proof of concept;
- the expected impact;
- any Layers request ID involved; and
- a safe way to contact you.

Do not include live credentials, customer source code, or personal data unless
Layers Security explicitly provides an approved transfer method.

We aim to acknowledge reports promptly and follow the standard
[disclose.io safe-harbor terms](https://disclose.io/).

## Supported versions

Security fixes are released on the latest published version of
`@layers/mcp-server`. Upgrade to the current npm release before reporting a bug
that may already have been fixed.
